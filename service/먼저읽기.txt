Windows x64 / Python 3.12 x64 · 2026-10-24

빠른 시작 — AI 없이 사용
1. ZIP을 새 폴더에 전부 풉니다. ZIP 안에서 실행하거나 기존 설치본 위에 덮어쓰지 않습니다.
2. 안쪽 '서무비서' 폴더에서 PowerShell을 엽니다. install-submission.bat 파일이 보여야 합니다.
3. Python 3.12 x64 및 Python Launcher를 별도로 설치한 뒤 다음 명령을 실행합니다.

py -3.12 --version
.\install-submission.bat
.\start-submission.bat

4. 서버 창에 Uvicorn running이 나오면 브라우저에서 다음 주소를 엽니다.
http://127.0.0.1:8781/start.html?v=69
5. '로컬 AI 보조 사용'은 처음에는 해제되어 있습니다. 그대로 질문하면 등록 자료와 검증한 요약·절차 규칙으로 안내합니다. Ollama·모델·API 키가 없어도 이 경로를 사용할 수 있습니다.
종료는 서버 창에서 Ctrl+C, 다시 시작은 같은 폴더에서 start-submission.bat입니다. 설치기는 최초 한 번 실행하면 됩니다.

같은 PC에서 8781 포트를 이미 사용하는 경우
.\start-submission.bat --port 8787
http://127.0.0.1:8787/start.html?v=69
127.0.0.1은 현재 PC 안에서만 연결되는 주소입니다. 실사용 앱과 확인용 사본은 포트를 다르게 사용하세요.

설치 내용과 별도 준비물
이 ZIP에는 Python 의존성 설치용 wheel 24개, 공개 법령·지침 25건, e-사람 매뉴얼 PDF 6개와 221쪽 전체 텍스트 색인, 앱 소스·화면 자산·테스트가 있습니다. 의존성은 동봉 wheel에서 설치하므로 설치 단계의 패키지 저장소 접속은 필요하지 않습니다.
Python 인터프리터, Ollama 등 모델 서버, 모델 가중치는 ZIP에 포함되지 않습니다. AI를 사용할 때 별도로 준비합니다. 새 PC에서는 ZIP을 풀어 새 .venv를 만드세요. 다른 PC의 .venv 폴더를 복사하는 방법을 안내하는 것이 아닙니다.
개인 업무 DB·기존 출장/취합 내역·개인 모델 설정·API 키는 동봉하지 않습니다. 최초 실행 시 clean data와 config.json을 생성하고 패키지 소유 원문을 복원합니다.

대화로 사용하기
업무 시작에 상황을 입력하고 '질문하고 시작하기'를 누르면 서무 안내에서 자동으로 답변을 찾습니다. 추가 질문은 같은 대화의 상황을 제한적으로 이어받고, '대화 지우기'는 그 상황을 초기화합니다.
답변에는 처리 순서·추가 확인사항·기한·관련 서식·법령 원문·e-사람 매뉴얼 쪽수가 연결됩니다. 법정 의무와 앱의 실무 준비 제안을 구분합니다. 정확한 근거가 없으면 금액·기한·조문을 만들지 않고 자료와 조건을 확인합니다.
출장 저장이나 이중 입력은 기본 단계가 아닙니다. 계산·정산·취합 등 보조 도구는 답변 아래 '계산·정산 등 도구가 필요할 때' 또는 왼쪽 '필요할 때 쓰는 업무 도구'에서 선택합니다. 기존 업무를 저장해 사용한다면 시작 화면에서 이어갈 수 있습니다.

첫 질문 예시
- 국가공무원인데 광주로 2박 3일 출장 다녀왔어. 개인차량을 사용했고 숙박은 2박했어. 정산 방법과 e-사람 사용법을 알려줘.
  → 관련 법령·기한·예시 서식·e-사람 조작 페이지를 함께 확인합니다. 실제 출장 날짜는 추측하지 않습니다.

  → 기한 요약의 근거 버튼을 눌러 공무원 여비 규정 제8조의2 원문을 확인합니다.
- 국가공무원 배우자 출산휴가는 며칠이야?
  → 등록 법령과 별표를 확인하고, 시스템 사용법은 별도로 구분합니다.
- 사무용품은 무슨 예산 목으로 사야 해?
  → 예산 근거를 찾으며, 질문과 무관한 검수 서식을 붙이지 않습니다.
- e-사람 초과근무 사후신청 목록이 안 보여.
  → 등록 초과근무 매뉴얼 PDF 16쪽 등의 해당 조작·주의사항을 확인합니다.
- 등록되지 않은 수당 지급액을 알려줘.
  → 무관한 규정을 대신 보여주지 않고 직접 근거와 업무 종류를 확인합니다.

근거·매뉴얼·서식 확인
'규정 원문·근거 자세히 보기'에서는 조문·출처·원문 해시를 확인합니다.
'e-사람 사용법 · 원문과 쪽수'를 펼치고 문서 항목을 열면 인용 원문, PDF 쪽수, '등록 매뉴얼 원문 PDF 열기'가 나옵니다. 정산 적용 예시에는 출장관리 14쪽, 스마트출장앱 교육 60쪽·81쪽 등이 연결됩니다. PDF의 #page 이동을 지원하지 않는 뷰어는 쪽수 칸에 번호를 입력하세요.
매뉴얼은 현재 기관 화면·권한과 다를 수 있으며, 매뉴얼의 화면 금액을 법정 지급 기준으로 사용하지 않습니다. e-사람·dBrain 실제 로그인·전송·결재·지급을 수행하는 연동 앱이 아닙니다.
서식 링크는 등록 사본을 내려받습니다. 합성·예시 서식 표시가 있으면 기관 현행 양식과 대조해 사용하세요. 답변 기록 저장은 안내와 법령·매뉴얼 근거를 구분해 TXT로 보관합니다.
'자료 연결 확인'은 업무·준비 단계·등록 서식·검색한 원문을 출처 ID/해시/쪽수와 함께 보여줍니다. 지도 자체가 법적 적용관계를 승인하지는 않습니다.

선택 — 로컬 AI 연결하기
AI 없이 쓰는 기능은 그대로 두고, 사용할 때만 모델을 준비합니다. Ollama를 별도 설치·실행한 뒤 원하는 모델을 내려받습니다. 최초 다운로드에는 인터넷과 모델별 저장 공간·메모리가 필요합니다.

ollama pull gemma3:4b
ollama pull llama3.2:3b
ollama list

서버를 Ctrl+C로 종료한 뒤 패키지 폴더에서 실제 설치한 모델에 맞는 설정 명령 하나를 실행합니다.
Gemma:
.\.venv\Scripts\python.exe tools\configure_submission_model.py --profile local_gemma --base-url http://127.0.0.1:11434/v1 --model gemma3:4b --json-object
Llama:
.\.venv\Scripts\python.exe tools\configure_submission_model.py --profile local_llama --base-url http://127.0.0.1:11434/v1 --model llama3.2:3b --json-object

다시 .\start-submission.bat 을 실행하고 화면을 새로고침합니다. 질문 입력 아래 '로컬 AI 보조 사용'을 켜서 질문합니다. 선택 모델을 설정해도 체크를 해제하면 그 질문에는 AI를 사용하지 않습니다.
화면 관리·설정의 모델 설정에서도 모델을 바꿀 수 있습니다. 모델명은 서버 설치 이름과 정확히 맞춰야 합니다. 대화의 AI 보조는 현재 같은 PC의 OpenAI 호환 HTTP 서버(127.0.0.1/localhost/::1)에 연결하는 경로입니다.
AI는 등록 원문 구절 선택을 보조합니다. 없는 인용은 채택하지 않고 원문 검색으로 돌아갑니다. 실제 모델 사용 여부는 답변 상단에 표시합니다. 서버 꺼짐·오류·모델 미선택 시에도 자료 기반 안내는 유지되며 AI를 사용했다고 표시하지 않습니다.
모델을 교체해도 법령·매뉴얼 PDF·색인·출처 ID·쪽수는 앱 자료로 남습니다. 자료를 모델 가중치에 학습시킨 구조가 아닙니다. Graphify나 Node.js는 앱 실행에 필요하지 않습니다.

문제 해결
- py -3.12가 없으면 Python 3.12 x64와 Launcher를 설치합니다.
- pip 설치가 실패하면 ZIP 전체를 풀었는지, wheels 폴더와 requirements-travel.lock.txt가 있는지 확인합니다.
- 주소가 열리지 않으면 서버 창 오류와 포트 중복을 확인합니다. AI 미설정은 실행을 막지 않습니다.
- AI가 사용되지 않으면 Ollama 실행 여부, ollama list, 설정한 서버 주소·모델명, 질문의 체크 상태를 확인합니다.
- 모델의 첫 로딩이 30초를 넘기면 원문 안내로 돌아갈 수 있습니다. Ollama에서 해당 모델을 먼저 실행해 준비한 뒤 같은 질문을 다시 보내세요. 예: ollama run gemma3:4b, 준비되면 /bye로 나옵니다. 검증에서도 첫 로딩 지연과 준비 후 성공을 구분합니다.
- 원문이 없거나 바뀌었다고 나오면 보관 사본을 임의로 덮어쓰지 말고 전체 ZIP의 무결성과 등록 상태를 확인합니다.

설치 폴더 이동과 자료 관리
같은 PC에서 설치 폴더 전체를 다른 경로로 옮길 때는 서버를 종료하고 폴더를 옮긴 다음 새 위치에서 .\.venv\Scripts\python.exe tools\restore_submission.py 를 실행합니다. 패키지 소유 원문 경로를 새 위치로 갱신하며 기존 설정·업무를 덮어쓰지 않습니다.
등록 사본은 data/manuals 및 복원된 자료함에 있습니다. 일반 폴더 분류용 미리보기와 매뉴얼 전체 페이지 색인은 별개입니다. 원본을 수정·삭제하면 근거에서 제외될 수 있습니다.
추가 매뉴얼은 tools\register_manuals.py "C:\매뉴얼폴더\파일.pdf"로 등록할 수 있습니다. 이번 추출은 이미지 속 글자를 전부 OCR한 결과가 아닙니다.
직접 PC 폴더 읽기는 같은 PC에서 접속할 때 사용하고, 업로드와 폴더 분석 등 보조 도구는 필요할 때만 엽니다. 계산 기준 확인 기간은 패키징만으로 늘리지 않습니다. 이번 묶음은 기존 확인 인증서와 규정팩을 유지합니다.
