01 · 요청을 실행할 일로

어떤 자료를 모으시나요?

기본 교육 서식 또는 기관에서 등록한 표 형태 XLSX를 선택하세요. 일반 자료는 선택한 열 기준으로 취합합니다. 기관의 공식 지침은 별도 확인하세요.

등록 원본과 열 연결을 버전별로 보관합니다. 2MB 이하 XLSX, 최대 10행의 다단 제목·최대 40개 열의 표를 지원합니다. 제목의 가로·세로 병합을 펼쳐 상·하위 제목을 연결합니다. 한 건이 여러 행이면 고정 행 묶음을 등록하고, 열별로 공통값 확인·내용 합치기·특정 행 읽기를 지정합니다. 지정한 열의 세로 병합값도 펼칩니다. 선택한 시트·데이터 영역만 읽고, 다른 시트·표 위 제목·끝 행 뒤 내용은 취합하지 않습니다. 수식은 회신에서 값으로 붙여넣으세요. 최종 결과는 원래 열 이름·순서를 유지한 새 표로 출력합니다.

여러 행 묶음은 끝 행을 필수로 지정합니다. 데이터 시작 행을 기준으로 같은 행 수씩 나누며, 완전히 빈 묶음은 건너뜁니다. 중간 행을 삭제하거나 가변 행 수로 작성한 회신은 이 기준에 맞게 정리하세요. 결과의 한 행이 한 사람·한 건입니다.

필수 열의 빈칸과 선택한 중복 기준 열을 검사합니다. 부서 의미를 연결하면 자동으로 회신 부서를 인식합니다. 부서 열이 없으면 업로드할 때 회신 부서를 직접 지정하세요. 교육 명단은 부서·성명·교육명·교육일·참석 희망 의미 연결이 필요합니다.

세로 병합값 펼치기는 부서 등 여러 행이 공유하는 열에만 허용하세요. 병합값만 있는 빈 행은 새 건으로 만들지 않습니다. 제목에서 하나의 항목으로 묶인 가로 병합은 한 열로 읽습니다. 서로 다른 항목을 합치거나 영역 경계를 넘는 데이터 병합은 취합하지 않습니다.

01 · 요청·서식

같은 양식으로 요청하세요.

회신 서식 XLSX 내려받기

제목 행과 열 순서가 같은 XLSX를 자동 병합합니다. 서식·수식·차트까지 합치는 기능은 아닙니다. 제공 서식: 부서 / 성명 / 직급(선택) / 교육명 / 교육일 / 참석 희망.

합성 예제에는 정상 회신·중복 의심·이름 누락·잘못된 서식이 들어 있습니다. 내려받아 압축을 풀고 직접 업로드해 볼 수 있습니다.

이 업무의 확인사항과 단계별 요령
  • 요청: 자료의 용도·취합 대상·마감일·필수 항목을 확인합니다.
  • 회신: 해당 자료가 없다는 회신과 미회신을 구분합니다.
  • 검토: 등록한 기준 열의 값이 같으면 중복을 의심합니다. 원본과 실제 대상을 대조한 사유를 남깁니다.
  • 마무리: 검토본은 참석 희망자 명단입니다. 교육 대상자 선정·참석 확정을 대신하지 않습니다.

앱의 실무 점검 제안이며 기관의 공식 근거 또는 실제 경험 사례가 아닙니다.

02 · 회신 수집

파일을 골라 한 번에 합치세요.

부서 열의 값이 한 부서로 일치하면 자동 인식합니다. 필요하면 파일별로 회신 부서를 지정하세요. 등록한 서식의 시트·제목 행·열 순서가 일치하는 파일만 합칩니다. 2MB 이하 XLSX, 파일당 2,000행, 업무당 50개 파일·5,000행까지 지원합니다. 원본은 로컬에 보관합니다.

03 · 병합·검토

한곳에 모인 명단을 확인하세요.

같은 서식은 행을 자동으로 이어 붙입니다. 모든 행은 보류 상태로 시작합니다. 정상 행을 일괄 포함하고, 오류·중복 의심은 원본과 대조해 수정 또는 제외하세요. 포함된 ‘미희망’ 행은 검토이력에만 남습니다.

04 · 취합본 저장

검토를 마친 명단을 내려받으세요.

포함 처리한 ‘희망’ 명단과 전체 검토이력·회신현황·출처 해시를 함께 저장합니다. 이후 회신이나 검토를 바꿔도 이전 취합본은 보존됩니다.
